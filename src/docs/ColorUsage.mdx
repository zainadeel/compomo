# Color usage

This page renders TokoMo's color guidance from the installed token package.
Expand a family, intent, or recipe variant below to see its selection rules
and token assignments.

## CompoMo integration

Import TokoMo once at the application root:

```ts
import '@ds-mo/tokens';
```

Components with a `background` or `surface` prop map their supported contexts
to the correct token families. Prefer that component API instead of manually
rebuilding its foreground, border, focus, and interaction mapping.

Prefer the owning component's `isInactive` API or native `disabled` state so
semantics and visuals stay synchronized. `aria-hidden` alone does not make
meaningful visible content decorative.

Checkbox uses `--color-foreground-tertiary` internally for its unchecked
outline, with the rendered 3:1 requirement verified on every supported surface.
Product code should use the component API rather than copying that internal
token choice.

Use `ds-divider` when a rule is part of component composition. Component
authors should use the shared interaction-fill and focus-ring utilities so
state layers compose in the correct paint order.

See the [Charts guide](?path=/docs/guides-charts--docs) for chart composition,
including CompoMo's chart-specific foreground hierarchy for labels and rules.
The live catalogs are available under
[Foundation → Colors Semantic](?path=/story/foundation-colors-semantic--backgrounds)
and [Foundation → Colors Data](?path=/story/foundation-colors-data--category).

## Forced colors

In Windows Contrast Themes and browser forced-colors mode, the OS owns the
actual palette. Keep `forced-color-adjust` at its default so CompoMo can map
boundaries, focus, selection, invalid, disabled, and loading states to the
user's system colors. Product code must not opt component chrome out of
forced colors.

Authored colors remain only for literal component-owned data marks whose color
encodes a category or value, such as chart marks and corresponding legend
swatches. Labels, focus, controls, and surrounding chrome still follow the OS
palette.
